# 🎮 Number Guessing Game

## 📌 About the Project
The Number Guessing Game is a beginner-friendly Python project. In this game, the computer randomly selects a number between 1 and 100, and the player has to guess the correct number.

The game gives hints to help the player guess the number.

## ✨ Features
- Random number generation.
- User-friendly interface.
- Gives hints (Too High / Too Low).
- Counts the number of attempts.
- Congratulates the player on winning.
- Runs until the correct number is guessed.

## 🛠️ Technologies Used
- Python 3
- Random Module
- While Loop
- If, Elif, Else
- User Input

**Step 2:** Clone this repository:


**Step 3:** Open the project folder:

```bash
cd guessing-game
```

**Step 4:** Run the Python file:

```bash
python guess_game.py
```

## 🎯 How to Play

1. Start the game.
2. The computer selects a random number between 1 and 100.
3. Enter your guessed number.
4. Follow the hints:
   - Too Low: Enter a higher number.
   - Too High: Enter a lower number.
   - Correct: You win!
5. Check your total attempts.
